# Дурак на вахте

Полностью локальная HTML5-игра: подкидной и переводной дурак против 1–3 ботов, с отдельным режимом «Вахтовый беспредел». Русский интерфейс, 18+ из-за переключаемой ненормативной лексики. Без ставок, рекламы, backend, SDK и внешних ресурсов во время игры.

## Быстро начать играть

Готовая сборка находится в [`releases/durak-na-vahte-offline.zip`](releases/durak-na-vahte-offline.zip). Скачайте файл целиком и распакуйте **всю** папку, сохранив `src/` и `public/` рядом с `index.html`.

1. Попробуйте открыть распакованный `index.html` в Chrome/Edge/Firefox. Код — обычные локальные скрипты, без ES-модулей и загрузки JSON через `fetch`.
2. Если браузер запрещает `file://` или не сохраняет данные для файлов, запустите статический сервер **без подключения к интернету**:
   ```sh
   cd путь/к/распакованной/игре
   python -m http.server 8080 --bind 127.0.0.1
   ```
   Откройте `http://127.0.0.1:8080/index.html`. Это раздача локальных файлов, а не игровой backend. На Windows команда Python может называться `py`.
3. При первом открытии по HTTP локальный service worker кеширует ресурсы. После его установки страницу можно перезагружать даже при недоступном сервере/в браузерном режиме Offline. В игровой логике нет зависимости от этого кеша: все файлы уже входят в ZIP.

**Интернет для игры не нужен. Node/npm во время игры не нужны.** Данные остаются в хранилище выбранного браузера и origin. При смене браузера/адреса перенесите прогресс через JSON-экспорт.

> В облачном тестовом Chromium переходы `file://` заблокированы административной политикой. Прямой двойной клик здесь не удалось проверить. Успешно проверен запуск через localhost, установка локального кеша, полное отключение сети, перезагрузка и прохождение реальных партий.

## Что реализовано

- 36 уникальных карт, 6–Т, четыре масти; видимый козырь — последняя настоящая карта стока.
- Подкидной и переводной на 2/3/4 участников. Один человек, остальные — боты с тремя сложностями и пятью характерами.
- Единый валидатор для всех ходов; ограничения подкидывания; покрытие; несколько переводов до первой защиты; взятие с завершением подкидывания; добор с защитником последним; выход, проигравший и ничья.
- Боты получают только свою руку, публичный стол/отбой, числа чужих карт и разрешённые действия. Чужих рук и будущего стока в их интерфейсе нет.
- Независимый модификатор событий: 2/4/6 скрытых жетонов, отдельная иллюстрированная колода из 30 происшествий, очередь между раундами. Отдача/обмен/списание карт, выбор целей, добор, круговая передача, однократный пропуск атаки и варианты выбора.
- Первый запуск с именем 2–24 буквы, пробелы/дефисы. Личные обращения NPC используют введённое имя. Пользовательские имена и журнал выводятся через `textContent`.
- 5 NPC с 4 эмоциями каждый; 70 контекстных реплик. Три режима юмора, отключение диалогов, настройка их частоты.
- Меню, состав/правила партии, стол, события, результаты, профиль, достижения, настройки, галерея 36 карт и 30 событий, просмотр карты крупнее.
- Локальный опыт и пять рангов, отдельные статистики классики/беспредела, шесть достижений с проверяемыми условиями. Альтернативная сгенерированная рубашка открывается за первое достижение; преимущества в картах не даёт.
- Сохранение текущей модели, порядка карт, RNG, очереди эффектов; резервная копия; JSON-экспорт/импорт с подтверждением; подтверждаемый сброс.
- Локальная оригинальная музыка и синтезированные звуки, отдельные громкости, пауза при скрытии вкладки/потере фокуса. Первый звук только после взаимодействия.
- Клавиатурные кнопки, управление тапами без обязательного drag-and-drop, увеличение карты. Уменьшение движения, быстрые ходы.

## Управление

Нажмите карту в руке. Для атаки или перевода подтвердите соответствующей кнопкой. Для защиты затем нажмите непокрытую атакующую карту на столе. «Взять» оставляет соперникам законную возможность подкинуть. Каждый атакующий по очереди завершает подкидывание. «Рассмотреть» увеличивает выбранную карту. Все кнопки доступны через Tab/Enter. В открытых модальных окнах фон заблокирован.

Переводной и беспредел — независимые настройки. Чтобы играть совсем без происшествий, снимите флажок «Вахтовый беспредел» перед новой партией.

## Разработка

Node.js 20+ для тестов/сборки; Python нужен только для удобного статического сервера и повторной генерации оригинальных звуков. Рабочая игра не использует npm-пакеты.

```sh
npm run build    # dist/index.html и все локальные ресурсы, автоматически сгенерированный sw.js
npm test         # 59 точечных тестов + 1000 полных симуляций
```

Для E2E установите dev-зависимость Playwright и Chromium:

```sh
npm install
npx playwright install chromium
npm run test:browser
```

Если используется системный Chromium, задайте `CHROMIUM_PATH=/путь/к/chromium`; иначе тест попробует `/usr/bin/chromium`, затем установленный Playwright Chromium. Во время подготовки использован предустановленный Playwright 1.63.0. `PLAYWRIGHT_MODULE` позволяет выбрать его путь без установки в проект. Интернет нужен только для установки отсутствующих средств разработки, не для игры.

E2E поднимает localhost:8788, заполняет первое имя, устанавливает кеш, включает Offline, проходит реальные партии кликами до победы, проверяет восстановление, экспорт/импорт и галереи. Исходное состояние не подменяется искусственным финалом.

## Структура

- `src/game/engine.js` — правила, автомат фаз, RNG, публичное наблюдение для ботов.
- `src/game/events.js` — проверенные атомарные эффекты и выборы.
- `src/game/save.js` — профиль, статистика, достижения, валидация импорта.
- `src/content/` — персонажи, реплики и данные 30 событий.
- `src/main.js`, `src/styles/main.css` — DOM-интерфейс и адаптация.
- `public/assets/` — локальные WebP-атласы, оригинальные PNG, шрифты с лицензией, WAV.
- `docs/screenshots/` — **настоящие скриншоты запущенной игры**, а не концепты.
- `docs/TEST_REPORT.md`, `docs/browser-results.json` — результаты проверок и ограничения.
- `CODEX_MASTER_PROMPT.md` — исходное задание.
- `references/README.md` — пояснение об отсутствовавших концептах.

## Честные ограничения версии 1.0

Концепты в пустом исходном репозитории отсутствовали; пользователь разрешил придумать стиль самостоятельно. Поэтому сравнения с пятью непредоставленными изображениями нет. Художественная графика действительно создана инструментом генерации изображений, не заменена CSS-персонажами или emoji. Иллюстрации хранятся атласами; крупные изображения событий мягче небольших карт из-за разрешения ячеек.

Автоматизированно проверен Chromium/Linux. Настоящие Android-устройства, Safari, Edge и Firefox отдельно не проверялись. `file://` в этой среде проверить не удалось, см. выше. Музыка и эффекты синтезированы; озвучки матерных реплик живыми голосами нет. Анимации — короткие переходы/выделения, без полноценного кинематографического переноса каждой карты из стопки. Фон статичный. Варианты внешнего вида ограничены рубашкой; второго полноценного фона бытовки нет.

Playgama/Yandex и любые публикационные интеграции намеренно отсутствуют: данное задание требует полностью офлайн-игру.
