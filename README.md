# Дурак на вахте

Полностью локальная HTML5-игра: подкидной и переводной дурак против 1–3 ботов, с отдельным режимом «Вахтовый беспредел». Русский интерфейс, 18+ из-за переключаемой ненормативной лексики. Без ставок, рекламы, backend, SDK и внешних ресурсов во время игры.

## Быстро начать играть

Готовая сборка находится в [`releases/durak-na-vahte-offline.zip`](releases/durak-na-vahte-offline.zip). Скачайте файл целиком и распакуйте **всю** папку, сохранив `src/` и `public/` рядом с `index.html`.

1. Попробуйте открыть распакованный `index.html` в Chrome/Edge/Firefox. Код — обычные локальные скрипты, без ES-модулей и загрузки JSON через `fetch`.
2. Если браузер запрещает `file://` или не сохраняет данные для файлов, запустите статический сервер **без подключения к интернету**:
   ```sh
   cd путь/к/распакованной/игре
   python -m http.server 8080 --bind 127.0.0.1
   ```
   Откройте `http://127.0.0.1:8080/index.html`. Это раздача локальных файлов, а не игровой backend. На Windows команда Python может называться `py`.
3. При первом открытии по HTTP локальный service worker кеширует ресурсы. После его установки страницу можно перезагружать даже при недоступном сервере/в браузерном режиме Offline. В игровой логике нет зависимости от этого кеша: все файлы уже входят в ZIP.

**Интернет для игры не нужен. Node/npm во время игры не нужны.** Данные остаются в хранилище выбранного браузера и origin. При смене браузера/адреса перенесите прогресс через JSON-экспорт.

> В облачном тестовом Chromium переходы `file://` заблокированы административной политикой. Прямой двойной клик здесь не удалось проверить. Успешно проверен запуск через localhost, установка локального кеша, полное отключение сети, перезагрузка и прохождение реальных партий.

## Что реализовано

- 36 уникальных карт, 6–Т, четыре масти; видимый козырь — последняя настоящая карта стока.
- Подкидной и переводной на 2/3/4 участников. Один человек, остальные — боты с тремя сложностями и пятью характерами.
- Единый валидатор для всех ходов; ограничения подкидывания; покрытие; несколько переводов до первой защиты; взятие с завершением подкидывания; добор с защитником последним; выход, проигравший и ничья.
- Боты получают только свою руку, публичный стол/отбой, числа чужих карт и разрешённые действия. Чужих рук и будущего стока в их интерфейсе нет.
- Независимый модификатор событий: 2/4/6 скрытых жетонов, отдельная иллюстрированная колода из 30 происшествий, очередь между раундами. Отдача/обмен/списание карт, выбор целей, добор, круговая передача, однократный пропуск атаки и варианты выбора.
- Первый запуск с именем 2–24 буквы, пробелы/дефисы. Личные обращения NPC используют введённое имя. Пользовательские имена и журнал выводятся через `textContent`.
- 10 NPC с 4 эмоциями каждый; 280 контекстных реплик. Три режима юмора, отключение диалогов, настройка их частоты.
- Меню, состав/правила партии, стол, события, результаты, профиль, достижения, настройки, галерея 36 игральных карт, просмотр карты крупнее.
- Локальный опыт и пять рангов, отдельные статистики классики/беспредела, шесть достижений с проверяемыми условиями. Альтернативная сгенерированная рубашка открывается за первое достижение; преимущества в картах не даёт.
- Сохранение текущей модели, порядка карт, RNG, очереди эффектов; резервная копия; JSON-экспорт/импорт с подтверждением; подтверждаемый сброс.
- Локальная оригинальная музыка и синтезированные звуки, отдельные громкости, пауза при скрытии вкладки/потере фокуса. Первый звук только после взаимодействия.
- Клавиатурные кнопки, управление тапами без обязательного drag-and-drop, увеличение карты. Уменьшение движения, быстрые ходы.

## Управление

Нажмите карту в руке. Для атаки или перевода подтвердите соответствующей кнопкой. Для защиты затем нажмите непокрытую атакующую карту на столе. «Взять» оставляет соперникам законную возможность подкинуть. Каждый атакующий по очереди завершает подкидывание. «Рассмотреть» увеличивает выбранную карту. Все кнопки доступны через Tab/Enter. В открытых модальных окнах фон заблокирован.

Переводной и беспредел — независимые настройки. Чтобы играть совсем без происшествий, снимите флажок «Вахтовый беспредел» перед новой партией.

## Разработка

Node.js 20+ для тестов/сборки; Python нужен только для удобного статического сервера и повторной генерации оригинальных звуков. Рабочая игра не использует npm-пакеты.

```sh
npm run build    # dist/index.html и все локальные ресурсы, автоматически сгенерированный sw.js
npm test         # 60 точечных тестов + 1000 полных симуляций
```

Для E2E установите dev-зависимость Playwright и Chromium:

```sh
npm install
npx playwright install chromium
npm run test:browser
```

Если используется системный Chromium, задайте `CHROMIUM_PATH=/путь/к/chromium`; иначе тест попробует `/usr/bin/chromium`, затем установленный Playwright Chromium. Во время подготовки использован предустановленный Playwright 1.63.0. `PLAYWRIGHT_MODULE` позволяет выбрать его путь без установки в проект. Интернет нужен только для установки отсутствующих средств разработки, не для игры.

E2E поднимает localhost:8788, заполняет первое имя, устанавливает кеш, включает Offline, проходит реальные партии кликами до победы, проверяет восстановление, экспорт/импорт и галереи. Исходное состояние не подменяется искусственным финалом.

## Структура

- `src/game/engine.js` — правила, автомат фаз, RNG, публичное наблюдение для ботов.
- `src/game/events.js` — проверенные атомарные эффекты и выборы.
- `src/game/save.js` — профиль, статистика, достижения, валидация импорта.
- `src/content/` — персонажи, реплики и данные 30 событий.
- `src/main.js`, `src/styles/main.css` — DOM-интерфейс и адаптация.
- `public/assets/` — локальные WebP-атласы, оригинальные PNG, шрифты с лицензией, WAV.
- `docs/screenshots/` — **настоящие скриншоты запущенной игры**, а не концепты.
- `docs/TEST_REPORT.md`, `docs/browser-results.json` — результаты проверок и ограничения.
- `CODEX_MASTER_PROMPT.md` — исходное задание.
- `references/README.md` — пояснение об отсутствовавших концептах.

## Честные ограничения версии 1.0

Концепты в пустом исходном репозитории отсутствовали; пользователь разрешил придумать стиль самостоятельно. Поэтому сравнения с пятью непредоставленными изображениями нет. Художественная графика действительно создана инструментом генерации изображений, не заменена CSS-персонажами или emoji. Иллюстрации хранятся атласами; крупные изображения событий мягче небольших карт из-за разрешения ячеек.

Автоматизированно проверен Chromium/Linux. Настоящие Android-устройства, Safari, Edge и Firefox отдельно не проверялись. `file://` в этой среде проверить не удалось, см. выше. Музыка и эффекты синтезированы; озвучки матерных реплик живыми голосами нет. Обычные игровые ходы, взятие/отбой и добор сопровождаются последовательными полётами карт; эффекты происшествий пока показываются карточкой и журналом изменений. Фон статичный. Варианты внешнего вида ограничены рубашкой; второго полноценного фона бытовки нет.

Playgama/Yandex и любые публикационные интеграции намеренно отсутствуют: данное задание требует полностью офлайн-игру.


## Изменения версии 1.1: мобильная игра и секретные происшествия

По новой просьбе пользователя просмотр всех происшествий удалён из галереи и со стола. Секретность относится к игровому интерфейсу: открывается только текущее сработавшее событие. Исходники офлайн-игры не зашифрованы.

Ранги и масти имеют непрозрачные контрастные плашки, козырь показан открытым без дополнительной подписи значения (убрана в 1.2). Иллюстрации сохраняют квадратные пропорции. Рука без скроллинга автоматически распределяется в перекрывающиеся ряды; у каждой карты доступна полоска ранга/масти. Для большой картинки есть «Рассмотреть». В низком альбомном окне убрана верхняя шапка, чтобы освободить место столу и руке.

`npm run test:mobile`: 24 сценария (6/12/24/35 карт; 360×800, 390×844, 412×915, 740×360, 844×390, 1366×768), проверка видимости и нажатия каждой карты до/после выделения, отсутствия прокрутки руки и доступа к просмотру происшествий. Стресс-скриншоты `mobile-*-hand*.png` используют искусственно подготовленное распределение карт только для тестирования раскладки, а не изображают результаты обычной партии. Остальные снимки browser-теста получены в настоящем игровом сценарии.


## Версия 1.2: последовательная анимация ходов

Убрана дополнительная плашка «Козырь ...». Полностью открытая козырная карта остаётся на месте.

`src/motion.js` — отдельный слой представления, не меняющий правила. Карта атаки/перевода летит из руки или от портрета NPC на стол; защита — к соответствующей атакующей карте. После выдержки на чтение карты стола уходят к взявшему или к обозначенному отбою. Добор летит из стока к участникам рубашкой. Подсвечивается действующий NPC, над экраном показано его имя и действие.

Обычный полёт занимает около 0,95 секунды, затем выдержка 0,25 секунды. Перед уходом стола в отбой/руку есть дополнительная выдержка 0,5 секунды. Новый ход бота начинается только после полного окончания предыдущей последовательности и паузы 1 секунда. Настройка «Ускорить» сокращает анимации; «Уменьшить движение» убирает перемещения.

Правила применяются атомарно и сохраняются до анимации. Ввод блокируется на время движения; при возобновлении после перезагрузки карта не теряется и не разыгрывается повторно. Начисление результата восстанавливается однократно, даже если закрыть игру во время финального полёта.

`npm run test:motion`: реальные координаты движущейся карты, блокировка второго действия, полёт в отбой/к взявшему, добор только рубашками, итоговый инвариант 36 карт и восстановление посреди полёта. Пройдена полная офлайн UI-партия с ожиданием анимаций. Снимок `motion-draw-mobile.png` — контролируемый тестовый расклад для проверки полёта, не выдуманный результат партии.


## Версия 1.3: профессии, новые коллеги и память козыря

Артём теперь монтажник. Обе его реплики в каждой категории переписаны: нет терминов про код, баги, патчи и разработку игр. Добавлены Виктор-экскаваторщик, Нина-повариха, Гена-охранник, Олег-прораб, Костя-разнорабочий. Теперь десять соперников, у каждого четыре нарисованных выражения лица, собственный темперамент и 28 тематических реплик (14 реакций × 2 варианта). Всего 280 вручную написанных реплик. Выбор вариантов учитывает недавние фразы и частоту диалогов; режим «Без мата» обрабатывает оба варианта.

После извлечения последней карты на месте стока остаётся крупная козырная масть: красные червы/бубны, тёмные пики/трефы. Пока карты в стоке есть, показывается сама открытая козырная карта, без дублирующей плашки.

Старые идентификаторы персонажей и нейтрального аватара сохранены; импорт прежних партий совместим. Дополнительные персонажи доступны и в выборе аватара.

Проверки: 60 тестов правил/контента/сохранений; 1000 полных симуляций с десятью темпераментами, 96533 действия, максимум 299, 1980 происшествий; без нелегальных ходов и нарушения инварианта карт. `npm run test:crew` проверяет запуск с каждым из десяти соперников и все четыре козырные масти после исчерпания стока на мобильном экране. `test:mobile` — прежние 24 сценария рук. Полный offline UI-сценарий запускает новую бригаду и проходит партию с анимациями.

Скриншоты `crew-selection-mobile.png` и `empty-stock-trump-mobile.png` показывают реальные экраны, второй использует контролируемое состояние без стока для проверки индикатора. Физическое Android-устройство отдельно не тестировалось.


## Версия 1.4: один экран без прокрутки

Все экраны занимают высоту окна с учётом безопасных полей устройства. Длинные коллекции перелистываются кнопками: бригада, 36 карт, портреты, достижения и памятки правил. Настройки и профиль разделены на вкладки. Условия новой партии отделены от выбора бригады; выбранные имена и кнопка запуска остаются перед глазами.

На игровом экране отдельная компактная панель управления, соперники сверху, стол в центре и собственная рука снизу. В низком альбомном окне кнопки игрока находятся справа от руки. Журнал и полные реплики открываются кнопкой «Реплики» с постраничным просмотром на паузе. Крупная рука раскладывается перекрывающимися рядами, сохраняя открытые ранги и масти. Иллюстрации карт и портреты сохраняют пропорции.

Происшествия раскрываются по шагам: история и эффект → распоряжение (если есть выбор) → цель → карта → подтверждение. На каждом этапе показаны только нужные органы управления. Можно вернуться назад; эффект применяется только при окончательном подтверждении. Уменьшение окна экранной клавиатурой не пересоздаёт активное текстовое поле и не стирает введённое имя.

`npm run test:viewport` проверяет все страницы на 360×640, 360×800, 390×844, 412×915, 740×360, 844×390, 1366×768, 1920×1080: отсутствие прокрутки и обрезанных элементов, доступность всех десяти NPC и 36 карт через перелистывание. Отдельно проверяются все 30 происшествий, выбор из 35 карт, шесть покрытых пар на столе и их читаемость на четырёх размерах. Реальные снимки — `docs/screenshots/viewport-*`. Проверки в Chromium с мобильными размерами; физическое Android-устройство и системная клавиатура отдельно не запускались.

`npm run test:results`: настоящая партия правил доводится до предпоследнего хода, последний ход выполняется через UI. Экран результата с четырьмя участниками проверен на 360×640, 390×844, 740×360 и 1366×768; нет переполнения, кнопки остаются на экране. Проверка уменьшенного окна при вводе имени имитирует изменение viewport и сохранение фокуса; она не является проверкой системной Android-клавиатуры.
