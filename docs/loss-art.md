# Иллюстрация поражения

Создана настоящим инструментом генерации изображений по образцу `npc.webp`. Сцена: тёплая бытовка, Палыч, Санёк и Артём смеются и указывают прямо на зрителя, карточный стол, чай и северная ночь за окном. Отдельная композиция без текста; подпись выводится интерфейсом с именем игрока.

Оригинал: `public/assets/originals/loss-crew.png` (1536×1024). Игровой файл: `public/assets/loss-crew.webp`, преобразование формата без изменения содержания, около 464 КБ. Оригиналы не включаются в офлайн-кэш, WebP включается.

Состав участников конкретной партии показан отдельно реальными портретами. Иллюстрация — общая сцена с тремя основными персонажами, а не отдельная генерация для каждой комбинации соперников.

Скриншоты реального экрана: `docs/screenshots/loss-screen-*.png`. В портретной ориентации изображение располагается над текстом, в альбомной — слева. Кнопки остаются доступны без прокрутки.
